# トラブルシューティング

## AIアフィリエイトサイト開発フレームワーク Version1.0

## 目的

このドキュメントは、開発中によく発生する問題と対処方法をまとめたものです。

------------------------------------------------------------------------

# Cursor関連

## Cursorが関係ないコードまで変更する

### 原因

一度に大きな範囲を実装させた。

### 対処

-   1STEPずつ実装する
-   「他のファイルは変更しない」と明記する
-   実装後は停止させる

------------------------------------------------------------------------

# OpenAI API

## APIキーエラー

### 原因

.envの設定ミス、APIキー未設定。

### 確認

-   OPENAI_API_KEY が設定されているか
-   .env が読み込まれているか

------------------------------------------------------------------------

# 楽天API

## 商品が取得できない

### 確認

-   Application ID
-   Affiliate ID
-   キーワード
-   API利用制限

------------------------------------------------------------------------

# WordPress

## 投稿できない

### 確認

-   REST API URL
-   Application Password
-   ユーザー名
-   投稿権限

------------------------------------------------------------------------

# Git

## Pushできない

### 確認

``` bash
git status
git pull
git push
```

競合がある場合は解消してからPushします。

------------------------------------------------------------------------

# Python

## ModuleNotFoundError

### 対処

``` bash
pip install -r requirements.txt
```

仮想環境を利用している場合は有効化してください。

------------------------------------------------------------------------

# .envが読み込めない

### 確認

-   python-dotenv をインストール
-   .env の配置場所
-   load_dotenv() を呼び出しているか

------------------------------------------------------------------------

# ログを確認する

エラー発生時は logs/ フォルダのログを確認します。

# 問題が解決しない場合

1.  エラーメッセージを確認
2.  ログを確認
3.  直前のコミットへ戻す
4.  小さい単位で再実装する
