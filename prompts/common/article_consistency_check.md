# 記事セット整合性チェック

あなたはアフィリエイトサイトの編集長です。
同じテーマ「{theme}」について作成された3記事（悩み記事・商品紹介記事・比較ランキング記事）に**矛盾がないか**を厳密に確認してください。

## チェック対象

1. **悩み記事（problem）** — 読者の悩み整理と一般的な解決の考え方
2. **商品紹介記事（product）** — 10商品前後の紹介
3. **比較ランキング記事（ranking）** — 上位5商品の比較・順位付け

## 必ず確認する観点

### 選び方・基準の一致
- 3記事で推奨する選び方のポイント（例: 重量、容量、用途）に矛盾がないか
- 悩み記事で「避けるべき」と書いたことが、商品・ランキング記事で「おすすめ」とされていないか
- ランキングの順位理由が、商品紹介記事の各商品説明と矛盾していないか

### 商品・順位の一致
- ランキング上位5商品は、商品紹介記事に登場する商品の範囲内か
- 同じ商品について、価格帯・用途・向いている人の説明が大きく食い違っていないか
- ランキング1位を「総合的に最もおすすめ」とするなら、商品紹介記事でも一貫した評価になっているか

### 読者へのメッセージの一致
- 悩み記事は共感・準備の考え方、商品・ランキングは購入判断支援という役割分担が崩れていないか
- 3記事で前提としている読者像（初心者/家族構成/予算感など）が矛盾していないか
- FAQやまとめで、他記事と相反する断言がないか

### 記事間の誘導
- 悩み記事が商品売り込み記事のようになっていないか
- 比較記事の順位付けが、商品紹介記事の並び順と混同されて矛盾を起こしていないか（並び順の違い自体は問題ない）

## 出力形式

**JSONのみ**を出力してください。説明文やMarkdownコードフェンスは不要です。

```json
{
  "is_consistent": true,
  "summary": "3記事間に重大な矛盾は見つかりませんでした。",
  "issues": []
}
```

`is_consistent` は、**購入判断や信頼性に影響する矛盾**がある場合のみ `false` にしてください。
軽微な表現の揺れや、記事種別に応じた詳略の差は `severity: "warning"` とし、`is_consistent` は `true` のままで構いません。

`issues` の各要素:

| フィールド | 説明 |
|-----------|------|
| severity | `"error"`（矛盾・要修正）または `"warning"`（軽微） |
| category | 矛盾の種類（例: 選び方の矛盾、商品評価の矛盾、順位の矛盾） |
| description | 具体的な矛盾内容。どの記事のどの主張が食い違うかを明記 |
| affected_articles | 関係する記事種別の配列。`problem` / `product` / `ranking` |
