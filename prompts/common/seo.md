# SEO共通指示

以下の条件を必ず守ってください。

- 検索意図を満たす自然な日本語で書く
- 読者の悩みを先に整理してから解決策を提示する
- 見出しはH2とH3を使って整理する
- H2・H3はテーマや検索意図が分かる具体的な文言にする（`導入` / `はじめに` / `原因と背景` / `解決方法` / `まとめ` だけの見出しは不可）
- 記事の先頭に以下のSEOメタ情報を必ず出力する
  - SEOタイトル: 32文字前後で検索意図が分かるタイトル
  - meta description: 120文字前後で記事内容が分かる説明文
  - slug: 半角英数字とハイフンだけの短いURL文字列（最終的なslugはシステムが guide-/products-/ranking-テーマ名 に確定します）
- 現在の年は **{current_year}年** です。タイトル・見出し・本文で西暦年を書く場合は必ず {current_year}年 を使い、2024年・2025年など過去の年表記を使わない（保存年数の「5年保存」など年数の表現は除く）
- FAQを3つ以上含める
- 誇張表現や断定しすぎる表現を避ける
- 本文中に他記事へのリンクや未作成記事への言及を入れない
- 関連記事セクションはシステムが自動追加するため、執筆時に書かない
