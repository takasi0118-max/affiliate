# 記事構成共通指示

対象テーマ: {theme}
記事種別: {article_type}
サイトカテゴリ: {category}
タグ候補: {tags}

以下の**内容の流れ**を基本にしてください（これは役割の一覧であり、H2の文言そのものではありません）。

1. 導入（H2は付けず、冒頭の本文だけで書く）
2. 読者の悩み
3. 原因や背景
4. 解決方法
5. 商品や比較への自然な導線
6. FAQ
7. まとめ

## 見出し（H2 / H3）のSEOルール（厳守）

- H2・H3は検索意図とテーマ「{theme}」が分かる具体的な文言にする
- 次のような**SEOに弱い一般名詞だけの見出しは使わない**
  - `導入` / `はじめに` / `概要` / `背景` / `原因と背景` / `原因や背景`
  - `読者の悩み` / `悩み` / `問題提起` / `解決方法` / `解決策` / `まとめ` だけの短い見出し
  - `ポイント` / `注意点` / `チェックリスト` だけの見出し
- 良い例（テーマに合わせて言い換える）
  - `## {theme}選びでよくある失敗と不安`
  - `## 災害時に{theme}の備えが必要になる理由`
  - `## 失敗しない{theme}の選び方`
  - `## {theme}に関するよくある質問（FAQ）`
  - `## {theme}の備えを始める前に押さえておきたいこと`
- H3も「内容が検索でも通じる具体文」にし、抽象語＋番号（例: `ポイント1`）だけで始めない

## 区切り線のルール（厳守）

- 導入文の直後、および各 H2 / H3 セクションの終了直後に、Markdownの水平線 `---` を入れる
- H2の直後（最初の段落の前）には入れない。セクション本文が終わった位置に入れる
- FAQセクションでは、各質問H3の間には `---` を入れず、FAQブロック全体の最後だけに入れる
- 「あわせて読みたい」がある場合は、その直前にだけ `---` を入れ、直後には入れない
- 既に `---` がある場合は二重にしない

Markdown形式で出力してください。
