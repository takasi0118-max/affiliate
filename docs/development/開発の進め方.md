# 開発の進め方

## AIアフィリエイトサイト開発フレームワーク Version1.0

このドキュメントは開発手順をまとめたものです。

## 開発フロー

1.  STEP開始
2.  Cursorへ指示
3.  実装
4.  動作確認
5.  Gitコミット
6.  GitHubへPush
7.  次のSTEP

## Cursorルール

-   1STEPずつ実装
-   関係ないファイルは変更しない
-   型ヒント・docstring必須
-   複雑な処理にはコメントを付ける
-   実装後は停止

## STEP01完了条件

-   フォルダ構成を作成済み
-   requirements.txt を作成済み
-   .env.example を作成済み
-   .gitignore に .env を設定済み
-   main.py が起動確認できる
