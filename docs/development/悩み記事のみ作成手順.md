# 悩み記事のみ作成手順

商品紹介・ランキングを含まない、**悩み記事だけ**を作成する手順です。
通常の3本セット（`main.py`）とは別運用です。

## いつ使うか

| 方法 | 用途 |
|------|------|
| `python main.py` | テーマ1つにつき悩み・商品・ランキングの**3本セット** |
| `python scripts/generate_problem_only.py` | 疑問文テーマで**悩み記事だけ**を1本作成 |

## 全体の流れ

```text
problem_themes.txt にテーマ（疑問文）を追加
problem_theme_slugs.json に英数字slugを追加
    ↓
python scripts/generate_problem_only.py
    ↓
sites/disaster/output/qa/{slug}/guide-{slug}.md を確認
    ↓
WordPress下書きを確認・公開
```

## テーマの書き方

`sites/disaster/themes.txt` とは別ファイルです。

`sites/disaster/problem_themes.txt` に1行1テーマ（疑問文・タイトル調）で書きます。

```text
# One problem-only theme (question-style title) per line.
防災グッズで最低限必要なものは？初心者向け準備リスト
1人暮らしに必要な防災グッズとは？最低限の備えを紹介
```

あわせて `sites/disaster/problem_theme_slugs.json` に対応slugを追加します。
slugは**短く・検索キーワードが分かる**英数字にしてください（2〜4語目安）。

```json
{
  "防災グッズで最低限必要なものは？初心者向け準備リスト": "minimum-bousai-goods",
  "1人暮らしに必要な防災グッズとは？最低限の備えを紹介": "solo-bousai-goods"
}
```

良い例: `minimum-bousai-goods` / `solo-bousai-goods` / `bousai-checklist`  
避けたい例: `essential-disaster-goods-beginner-preparation-list`（長すぎる）
## コマンド

プロジェクト直下で実行します。

```powershell
# 未処理テーマ一覧
python scripts\generate_problem_only.py --list

# 先頭の未処理テーマを1件生成（Markdown保存 + WordPress下書き）
python scripts\generate_problem_only.py
```

## 生成時の仕様

- WordPress / Markdown の slug は必ず **`guide-{短いslug}`**（例: `guide-minimum-bousai-goods`）
- 文字数目安: **2000〜3000文字**
- SEO重視: 結論先出し、テーマキーワードを含むH2/H3、検索されやすいFAQ
- 楽天商品取得は行わない
- 既存の `sites/disaster/output` / `history.json` から関連記事を選び、本文にリンクを付与
  - 各H2セクション末尾の「あわせて読みたい」を **3〜5件**
  - 末尾「関連記事」を **3件**
  - あわせて読みたいと関連記事で**同じ記事は重複させない**
- 履歴は `sites/disaster/problem_history.json` に記録（通常の `history.json` / `themes.txt` には影響しない）

## 出力先

```text
sites/disaster/output/qa/{slug}/guide-{slug}.md
```

例: テーマslug が `minimum-bousai-goods` の場合  
→ `sites/disaster/output/qa/minimum-bousai-goods/guide-minimum-bousai-goods.md`  
→ WordPress slug: `guide-minimum-bousai-goods`
## 注意

- `main.py` の3本セット処理とは独立しています
- WordPress更新は次のコマンドです（`problem_history.json` の投稿IDも対象）

```powershell
python scripts\update_wordpress_posts.py 1227
```
