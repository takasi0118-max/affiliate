# コーディング規約

## AIアフィリエイトサイト開発フレームワーク Version1.0

## 目的

本プロジェクトで作成するPythonコードの品質・保守性・再利用性を高めるためのルールを定義します。

## 基本方針

-   Python 3.13.5
-   PEP8準拠
-   型ヒント必須
-   docstring必須
-   コメントを記述する
-   共通処理とサイト固有処理を分離する

## 命名規則

### ファイル

-   snake_case

### 関数

-   snake_case

### クラス

-   PascalCase

### 変数

意味が分かる名前を使用する

## 型ヒント

すべての関数に型ヒントを付与します。

## docstring

公開関数にはdocstringを記述します。

## コメント

複雑な処理には説明コメントを付けます。

## エラー処理

-   try-exceptを使用
-   楽天APIは3回リトライ
-   OpenAIは2回リトライ
-   WordPressはログ出力

## ログ

loggingモジュールを使用します。

## APIキー

APIキーは .env で管理し、コードへ直接書きません。

## フォルダ構成

-   config
-   providers
-   services
-   prompts
-   sites
-   utils
-   tests
-   logs

## テスト

追加した機能は必ず動作確認します。
